# Security policy

## Report a vulnerability

Please do not open a public issue for a security problem.

Use GitHub private vulnerability reporting instead:

1. Open the repository on GitHub.
2. Go to the "Security" tab.
3. Click "Report a vulnerability".

Describe the problem, the version you use, and the steps to reproduce it. You will get an answer as soon as possible.

## Supported versions

Only the latest release receives security fixes. While the package is in version 0.x, please update to the latest version before you report a problem.

| Version | Supported |
| ------- | --------- |
| latest release | yes |
| older releases | no |
